# Campus photos

Drop real photos here. Nothing in this folder is a stock or generated image.

| File | Where it shows | Size |
|---|---|---|
| `login.jpg` | Above the sign-in card | 1600 px wide, 16:7 crop, under 250 KB |
| `au-info.jpg` | Top of the AU Info page | 1600 px wide, 16:7 crop, under 250 KB |

Then open `app/campus-photos.ts` and fill in `credit` and `licence` for each photo
(for example your own name and "own photo"). The credit is printed on the photo.

Use only photos you took, photos the university gave you permission to use, or photos
with a licence that allows it (for example Creative Commons, with the attribution it requires).
Do not copy photos from college-listing or stock sites. If a file is missing the slot
renders nothing, so the app looks normal without photos.
