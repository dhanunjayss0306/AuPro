# AuPro campus map prototype plan

This is a prototype plan, not a finished screen and not final visual styling.

## Web/mobile prototype states

1. Map canvas with a clearly marked College of Engineering sample boundary.
2. Search field and category shortcuts.
3. Current-location control with permission state.
4. Place marker and bottom/detail sheet.
5. Walking-route preview between two sample places.
6. Offline-region download state.
7. Suggest-a-correction form.

## Navigation

The current AuPro navigation has six items after the location addition:

`Applications | Chatbot | Create (+) | Feed | About | Location`

This is a temporary structural decision for the prototype because the user selected six items. Iconography, color, spacing, and final desktop layout remain subject to design approval.

## Data safety

Use synthetic/sample place names and coordinates in the prototype. Do not present unverified university data as authoritative and do not copy third-party map tiles or photos without permission.
